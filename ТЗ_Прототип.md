# Wolfish Revenge — ТЗ на игровой прототип

Документ фиксирует согласованные требования к игровому прототипу. Разделы будут дополняться по мере обсуждения.

## 1. Персонаж

### 1.1 Здоровье и броня

- Реализовать систему здоровья игрока.
  - Максимальное здоровье: **100 HP** на протяжении всей игры.
  - Лечение не увеличивает максимальный запас здоровья.

- Реализовать лечение аптечками.
  - Подобранная аптечка помещается в слот инвентаря.
  - Аптечку можно применить в любой форме персонажа.
  - Для применения назначается горячая клавиша.

- Реализовать получение урона:
  - от пуль;
  - от взрывов;
  - при соприкосновении с зонами урона;
  - от падения.
  - Урон от падения в форме оборотня должен быть в несколько раз ниже, чем в человеческой форме, но не равен нулю.
  - Падение в пропасть всегда убивает персонажа.

- Реализовать систему брони.
  - Броня подбирается в мире.
  - Наличие брони отображается в HUD.
  - Броня снижает входящий урон только от пуль и взрывов.
  - Броня не расходуется и не имеет прочности.
  - После подбора игрок получает постоянный бонус сопротивления урону до конца игры.

### 1.2 Инвентарь и оружие

- Реализовать упрощённый инвентарь со слотами: полноценная сетка предметов не требуется.
- Игрок может носить до трёх единиц оружия.
  - Слоты оружия назначаются на клавиши `1`, `2`, `3`.

- Реализовать подбор оружия.
  - Игрок наводит прицел на оружие в мире и нажимает `E`.
  - Подобранное оружие занимает активный слот.
  - Если активный слот уже занят, новое оружие заменяет находящееся в нём.

- Реализовать отображение убранного оружия на персонаже.
  - Неактивное оружие отображается на соответствующих сокетах модели персонажа.

- Реализовать смену оружия между слотами.
- Реализовать анимации подбора предметов.

- Реализовать отдельные слоты для гранат.
  - Количество слотов для гранат зависит от надетой брони.
  - Без брони доступен **1 слот** для гранат.
  - После подбора первой брони доступно **3 слота** для гранат.

## 2. Контроллер игрока

### 2.1 Камера

- Реализовать камеру от третьего лица.
- Камера следует за персонажем во всех состояниях.
- При использовании огнестрельного оружия камера смещается в сторону, обеспечивая обзор через плечо персонажа.
- В человеческой форме камера остаётся смещённой в сторону.
- В форме оборотня, если оружие убрано, камера центрируется за персонажем.
- Реализовать возможность переключать камеру в заранее подготовленные ракурсы для эпичных игровых моментов.

### 2.2 Перемещение

- Реализовать систему перемещения для двух форм персонажа: человека и оборотня.

- Реализовать ускорение в форме оборотня.
  - Оборотень перемещается быстрее персонажа в человеческой форме.
  - Если в форме оборотня оружие убрано, персонаж переходит на бег на четырёх лапах.

- Реализовать прыжки в обеих формах.
  - В режиме бега на четырёх лапах прыжок должен быть усиленным.
  - При убранном оружии игрок может заряжать прыжок удержанием `Space`. 
  - При отпускании `Space` персонаж выполняет высокий прыжок — до 7 метров по вертикали. 

- Реализовать упрощённую систему преодоления препятствий.
  - Если персонаж допрыгнул до доступного для преодоления края, он хватается за него и подтягивается.
  - В форме оборотня подтягивание выполняется значительно быстрее.
  - Тонкие стены персонаж не занимает сверху, а перелезает через них.
  - Очень низкие препятствия персонаж быстро преодолевает проскальзыванием.

- Реализовать подкат.
  - При быстром беге и нажатии приседа персонаж выполняет быстрый подкат.
  - Во время подката игрок может продолжать стрельбу.
  - В форме оборотня подкат должен быть существенно быстрее и длиннее.
  - Подкат оборотня сбивает врагов с ног с использованием ragdoll-физики.

- Реализовать приседание.
  - В приседе персонаж перемещается медленнее.
  - Приседание обеспечивает скрытное передвижение.
  - В приседе повышается точность стрельбы.

### 2.3 Трансформация

- Реализовать автоматическую трансформацию между человеческой формой и формой оборотня.
- Состояние формы определяется рейкастом к гипотетическому источнику лунного света.
  - Если луч до луны не прерывается препятствиями, персонаж находится в форме оборотня.
  - Если луч прерывается, персонаж переходит в человеческую форму.

- Реализовать различную скорость трансформации.
  - Превращение из человека в оборотня происходит почти мгновенно.
  - Превращение из оборотня в человека занимает несколько секунд.

- Реализовать визуальную систему морфинга при трансформации.
  - Изменение модели и пропорций персонажа.
  - Смещение и адаптация сокетов для оружия и снаряжения.
  - Корректное обновление связанных анимаций и отображаемых предметов.

- В форме оборотня увеличить угол обзора камеры.

### 2.4 Стрельба и атаки

- Реализовать систему стрельбы:
  - выстрелы из огнестрельного оружия;
  - прицеливание;
  - разброс пуль;
  - параметры точности в зависимости от состояния персонажа, включая бонус точности в приседе.

- Реализовать атаку ножом.
  - Обычный удар ножом.
  - Удар ножом по врагу из скрытности выполняет скрытное убийство.

- Реализовать атаки лапами в форме оборотня.
  - Удары наносятся лапами поочерёдно.
  - Удар лапой по врагу из скрытности выполняет скрытное убийство.

- Реализовать атаку «наброситься».
  - Если враг находится в пределах 6 метров по горизонтальной плоскости относительно игрока, доступна атака по кнопке.
  - Вертикальное смещение между персонажем и врагом не должно мешать атаке: на врага можно наброситься, если он находится ниже игрока, при соблюдении горизонтальной дистанции.
  - Во время анимации набрасывания управление персонажем блокируется.
  - При атаке на близко стоящего врага используется более быстрая отдельная анимация, визуально похожая на добивание.
  - Набрасывание можно использовать из скрытности.

- Реализовать удержание атаки «наброситься» для пожирания врага.
  - Пожирание восстанавливает здоровье персонажа.
  - На труп также можно наброситься и начать пожирание.
  - Для уже мёртвого врага используется упрощённая анимация пожирания.

## 3. NPC

### 3.1 Перемещение

- Реализовать упрощённое перемещение NPC.
  - В состоянии без тревоги NPC находится в режиме ожидания (idle).
  - NPC перемещается между заданными точками патрулирования.

### 3.2 Поведение

- Реализовать систему чувств NPC.
  - Зрение.
  - Слух.
  - Реакция на соседних NPC: NPC должен реагировать на тревогу и действия других NPC поблизости.

- Реализовать систему поиска укрытий.
  - NPC должен находить и занимать доступные укрытия в боевой ситуации.

- Реализовать систему стрельбы NPC.

- Реализовать систему повреждения нпс, здоровье, реакция на урон, смерть 

### 3.3 Взаимодействия

- Реализовать взаимодействия NPC с игровыми ситуациями и окружением. Детали будут определены отдельно.

## 4. Уровень

### 4.1 Взаимодействия с окружением

- Реализовать взаимодействие с различными объектами окружения.
  - Подбор объектов.
  - Включение и выключение объектов.
  - Активация рычагов.
  - Другие контекстные взаимодействия при необходимости.

- Реализовать механику переворота объектов для создания укрытий.
  - Возможность переворота зависит от массы и типа объекта.
  - В человеческой форме игрок может переворачивать мебель.
  - В форме оборотня игрок может переворачивать автомобили и другие крупные конструкции.

### 4.2 Разрушения

- Реализовать базовую систему разрушения объектов окружения.
- Поведение объекта при воздействии зависит от его типа прочности.

| Тип объекта | Разрушающие воздействия |
| --- | --- |
| Хрупкий | Пули, скоростное перемещение оборотня, взрывы. |
| Средний | Скоростное перемещение оборотня, взрывы. |
| Крепкий | Взрывы. |
| Нерушимый | Не разрушается; может смещаться и деформироваться от взрывов. |

## 5. UI

### 5.1 HUD

- Реализовать основной HUD.
  - Шкала здоровья.
  - Слоты оружия с подписями назначенных горячих клавиш.
  - Слоты гранат с подписями горячих клавиш.
  - Слот аптечки с подписью горячей клавиши.
  - Шкала зарядки прыжка при удержании `Space`.

### 5.2 Меню

- Реализовать простое меню с основными кнопками.

### 5.3 Маркеры и обратная связь

- Реализовать маркеры попаданий по врагам.
- Реализовать визуальную индикацию попаданий по игроку.
  - При получении урона соответствующий сектор экрана окрашивается в красный цвет.
  - Сектор определяется направлением, откуда был получен урон.

### 5.4 Подсказки

- Реализовать контекстные подсказки по управлению и взаимодействиям.
